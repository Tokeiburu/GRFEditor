# Protected GRF regression checks

This console harness targets .NET Framework 4.8 and runs on Windows without a
testing framework. Build and run it from the repository root with a .NET SDK:

```powershell
dotnet build Tests/ProtectedGrfTests.csproj "-p:SolutionDir=$((Get-Location).Path)\"
& ./Tests/bin/Debug/net48/ProtectedGrfTests.exe
```

The repository's existing build targets refresh the DLLs in `Libraries`, so use
a disposable source copy when those tracked binaries must remain unchanged.

The two grouped checks cover:

- A shared bundle of 25 successful decoder vectors and 15 malformed vectors,
  including body-cipher boundaries, stored/zlib/LZ4 data, footer keys, invalid
  sizes, integrity failures and invalid padding.
- A small generated GRF 3 archive containing a protected CP949 filename, an
  archive key footer, and an ordinary filename with forward slashes. It checks
  single reads, bulk extraction, generic callbacks, SaveAs/RepackAs preservation,
  refusal to save a renamed protected entry before creating output, and an
  ordinary GRF 2 record.

`fixtures/protected-grf.bin` contains generated bytes only, shared with the Rust
reader regression harness. It contains no client files. The format is a
little-endian record count, then five length-prefixed byte fields per record
(UTF-8 tag, original filename, archive key block, protected payload, expected
output), followed by the expected output size as a 32-bit integer.
